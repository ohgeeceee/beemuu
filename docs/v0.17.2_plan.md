# BeeEmUu v0.17.2 — Cycle Plan

> **Status:** Planned. Ships after v0.17.1.

## Premise

v0.17.1 polished the UI. v0.17.2 adds **snapshot bundle v2** —
improving the self-contained HTML export with better formatting,
multi-vehicle comparison support, and a cleaner layout.

## Cycle scope

### PR #1 — Snapshot HTML template refresh (Tier A)

Redesign the walkthrough bundle HTML output (`walkthrough_bundle.js`)
with a cleaner layout, better typography, and responsive design.
The current output is functional but dense.

**Files**
- `src/js/walkthrough_bundle.js` — template HTML/CSS refresh
- `src/js/test/walkthrough_bundle.test.js` — updated assertions

**Acceptance.** Exported HTML looks good on desktop and mobile.
All existing tests pass with updated expected output.

### PR #2 — Multi-vehicle snapshot comparison (Tier A)

Add a comparison mode to the snapshot viewer: load two exported
`.html` files side-by-side to compare freeze-frame values and
walk results between vehicles or sessions.

**Files**
- `src/js/snapshot_compare.js` — new comparison logic
- `src/js/test/snapshot_compare.test.js` — new tests
- `src/index.html` — comparison UI card

**Acceptance.** Load two snapshots; differences highlighted.
`node --test` passes.

### PR #3 — Export to JSON (Tier A)

Add a JSON export option alongside the HTML export. The JSON
contains the same snapshot data (plan, answers, freeze-frame,
meta) in a machine-readable format for downstream tools.

**Files**
- `src/js/walkthrough_bundle.js` — `buildSnapshotJson()` function
- `src/js/test/walkthrough_bundle.test.js` — JSON export tests

**Acceptance.** JSON export produces valid JSON with all expected
fields. `node --test` passes.

## What does NOT ship in v0.17.2

- ❌ No `transport/**`, `protocol/**`, or `commands.rs` changes
- ❌ No cloud sync or upload — all local

## Test plan

- `node --test src/js/test/*.test.cjs` — full JS suite
- Manual: export HTML + JSON, verify both render correctly
