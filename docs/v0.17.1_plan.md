# BeeEmUu v0.17.1 — Cycle Plan

> **Status:** Planned. Ships after v0.17.0.

## Premise

v0.17.0 expanded the E-series data surface (CAN decoders, DTC texts,
vehicle DB). v0.17.1 focuses on **UI polish** — dark mode refinements,
accessibility improvements, and mobile CSS hardening.

## Cycle scope

### PR #1 — Dark mode refinements (Tier A)

Audit the dark/light theme across all tabs. Fix any elements that
don't theme correctly (hardcoded white backgrounds, low-contrast
text, missing hover states).

**Files**
- `src/css/app.css` — theme variable fixes
- `src/js/main.js` — any theme-toggle edge cases

**Acceptance.** Toggle dark/light mode on every tab; no unstyled
elements. `node --test` passes.

### PR #2 — Accessibility pass (Tier A)

Add ARIA labels, keyboard navigation, and focus indicators to
interactive elements. Ensure the language selector, connection
dropdown, and tab bar are keyboard-accessible.

**Files**
- `src/index.html` — ARIA attributes
- `src/css/app.css` — focus-visible styles

**Acceptance.** Tab through the entire UI with keyboard only.
Screen reader announces key elements. `node --test` passes.

### PR #3 — Mobile CSS hardening (Tier A)

Test the v0.16.0 mobile CSS on additional viewports (320px, 375px,
768px). Fix overflow, clipping, or touch-target issues.

**Files**
- `src/css/app.css` — responsive breakpoints

**Acceptance.** No horizontal scroll on any tab at 320px width.
All buttons are at least 44px touch targets. `node --test` passes.

## What does NOT ship in v0.17.1

- ❌ No `transport/**`, `protocol/**`, or `commands.rs` changes
- ❌ No new features — polish only

## Test plan

- `node --test src/js/test/*.test.cjs` — full JS suite
- Manual testing on narrow viewports
