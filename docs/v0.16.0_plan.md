# BeeEmUu v0.16.0 — Cycle Plan

> **Status:** Shipped 2026-08-31. All items implemented and tested (88 tests pass).

## Premise

v0.15.x delivered the **tuner logging workflow** (injector duty, triggers, math channels, workspace) + **external log import** + **CAN validation harness** + **vehicle DB**. What's left is **sharing** — getting a log off the laptop without emailing a CSV, plus polish and reach.

v0.16.0 picks cycle name **"Share the Trace"** because the work is about turning the now-rich logging pipeline into a shareable artifact: a web-based viewer for shared logs (no app needed to view a friend's trace), plus the small docs that make sharing trustworthy.

This cycle shipped as v0.16–v0.20 feature slices, all merged to main.

## What does NOT ship in v0.16.0 (deferred)

- Cloud sync (opt-in log upload with auth) — needs privacy + ops story
- Raspberry Pi CAN bridge — hardware project
- Bootmod3/MHD flash (write) — legal risk, stays deferred per `docs/proposals/bootmod3-mhd-scope.md`
- BLE / WiFi / ENET auto-detect transport — Tier B, deferred
- ECU write routines, flashing, SecurityAccess changes — Tier B/C
