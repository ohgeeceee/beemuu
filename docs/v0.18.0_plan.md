# BeeEmUu v0.18.0 — Cycle Plan

> **Status:** Implementation complete; release remains pending. Follows v0.17.2.

## Premise

v0.17.x delivered E-series data expansion + UI polish + snapshot v2.
v0.18.0 adds **logging enhancements** — session tagging, log
bookmarks, and improved CSV export.

## Cycle scope

### PR #1 — Session tagging (Tier A) - complete

Let users tag a logging session with a label (e.g. "WOT pull",
"highway cruise", "cold start") before or during recording. Tags
are saved in the CSV header and shown in the Logging tab session
list.

**Files**
- `src/index.html` — session tag input field
- `src/js/main.js` — tag wiring into log start
- `src/js/logging.js` (if exists) — tag persistence

**Acceptance.** Tag appears in CSV header. Session list shows tag.
`node --test` passes.

### PR #2 — Log bookmarks (Tier A) - complete

Add bookmark markers during logging: press a button to mark a
point in time ("this is where the knock happened"). Bookmarks are
saved as annotations in the CSV and shown as vertical lines on the
chart.

**Files**
- `src/js/chart_annotations.js` — bookmark rendering
- `src/js/main.js` — bookmark button wiring
- `src/js/test/chart_annotations.test.js` — new tests

**Acceptance.** Bookmarks appear on chart at correct timestamps.
Exported CSV includes bookmark annotations. `node --test` passes.

### PR #3 — CSV export improvements (Tier A) - complete

Improve the CSV export with:
- Configurable delimiter (comma vs semicolon for EU Excel)
- Header row with metadata (VIN, profile, date, tags)
- Option to export only selected channels

**Files**
- `src/js/csv_export.js` — export improvements
- `src/js/test/csv_export.test.js` — new tests

**Acceptance.** Export offers comma or semicolon delimiters, metadata for
VIN/profile/date/tag, bookmarks, and selected-channel filtering. All CSV
exporter tests pass.

## What does NOT ship in v0.18.0

- ❌ No cloud sync — all local file operations
