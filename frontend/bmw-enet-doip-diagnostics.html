What ENET / DoIP is

ENET is BMW's Ethernet diagnostic interface. The modules speak DoIP (Diagnostics over IP), the same UDS services wrapped in an IP transport instead of a serial line.

Vehicle discovery, addressing and the DME pinout are on the protocols guide.

Which cars use it

  • F20 / F30 / F31 (1 and 3 Series)
  • F10 (5 Series)
  • F15 / F16 (X5 / X6)
  • G20 / G30 and later

Older E-series cars use K+DCAN.

What you can read

The same fault memory and live-data surface as K+DCAN, over a faster link. See the engine profiles and the fault-code index.
