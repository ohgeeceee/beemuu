Cycle-roadmap questions

How do I propose a new cycle?

Open an issue on GitHub with the proposed scope. The maintainers will turn it into a plan doc under docs/vX.Y.Z_plan.md and call for PRs.

Where is the canonical roadmap?

github.com/ohgeeceee/beemuu/blob/main/ROADMAP.md. The per-cycle pages are rendered versions of the plan docs there.
