Open questions

For the maintainer:

  1. Is the v0.14.6 release cut a separate PR?

    Per CLAUDE.md golden rule #5 ("don't let the badge lie"), the README release badge reflects the most recent fully shipped release. A docs-only cycle still counts as shipped for the badge; the v0.14.6 release cut is therefore a separate Tier C PR (mirror of PR #225) that bumps the version surface to 0.14.6. Default: yes, the v0.14.6 release cut is a separate PR.

  2. Should the v0.14.6 cycle also fix the release.yml landing-page step?

    The v0.14.5 release run (#30738207436) failed at the "Update beemuu.com landing page" step because the BEEMUU_VPS_SSH_KEY / BEEMUU_VPS_HOST secrets aren't configured in the repo. The v0.14.6 cycle could ship a release.yml change that makes the landing-page step best-effort + documents the secret-requirements in a new docs/ops/release-yml-secrets.md. Default: yes, ship the docs change in v0.14.6 alongside the audit PR.
