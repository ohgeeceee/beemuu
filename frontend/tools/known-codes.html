BMW-specific fault codes.

BMW uses 4-hex-digit codes in addition to the standard SAE J2012 codes. The first two hex digits identify the subsystem. The full catalog has 220 BMW-specific entries; this page lists the high-traffic families with direct links to each code’s diagnostic page.

27xx — Accelerator pedal & throttle

The accelerator pedal module (and its sensors) and the electronic throttle body. Codes in the 27xx family are the most common for “reduced power mode” complaints.

  • 2710 — Throttle valve, function: jammed permanently
  • 2711 — Throttle valve, function: jammed briefly
  • 2714 — Throttle valve, function: sluggish, too slow
  • 27D9 — Accelerator pedal module, pedal sensor 1, short circuit to B+
  • 27DA — Accelerator pedal module, pedal sensor 1, short circuit to earth
  • 27DB — Pedal module, pedal sensor 2, short circuit to B+
  • 27DC — Pedal module, pedal sensor 2, short circuit to earth
  • 27E4 — Accelerator-pedal module, pedal-travel sensor multiple fault
  • 27E8 — Accelerator pedal module, synchronisation error between signal 1 and 2

28xx — Intake manifold pressure

The MAP sensor reports intake manifold pressure to the DME. 28xx codes are a manifold pressure disagreement or sensor fault.

  • 280E — Absolute pressure sensor, intake manifold, plausibility: intake-manifold
  • 280F — Absolute pressure sensor, intake manifold, plausibility: intake-manifold
  • 281A — Absolute pressure sensor, intake pipe, electrical: short circuit to B+

29xx — Fuel rail pressure

The high-pressure fuel rail pressure family. The N54’s headline failure mode. 29E0/29E1/29E2 are early indicators of HPFP failure on the N54; on the N55 and B58 the HPFP is more reliable but the rail-pressure sensor can still fail.

  • 29E0 — Fuel injection rail, pressure sensor signal
  • 29E1 — Fuel pressure sensor signal (low / implausible)
  • 29E2 — Fuel pressure sensor signal (high)

2Axx — VANOS

BMW’s variable valve-timing system. Intake and exhaust camshafts each have their own VANOS solenoid; a 2A82 means the intake solenoid is stuck or its screen is clogged. Higher-mileage cars are the common case.

  • 2A82 — VANOS intake control fault (N52/N54/N55/B58)
  • 2A99 — VANOS exhaust: control fault, camshaft stuck (community list)

30xx — Boost / charging pressure

Turbocharger boost pressure. 30FF is the most common code on turbocharged BMWs; “charge-air pressure too low (underboost)” points at boost leak, wastegate, or N75 valve.

  • 30FF — Turbocharger, charge-air pressure too low (underboost)

2Exx — Electric coolant pump

The electric coolant pump is electronically controlled on F/G-series BMWs. Codes 2E81 and 2E82 are communication and speed-signal faults.

  • 2E81 — Electric coolant pump, communication
  • 2E82 — Electric coolant pump, speed signal

29CC — Cylinder 1-4 misfire (BMW 6-cyl layout)

The 29CC code is a BMW-specific misfire code that covers the full bank on a 6-cylinder. It’s a different code from the SAE P0300 (random misfire) and the per-cylinder P0301–P0306 codes.

  • 29CC — Cylinder 1-4 misfire detected (BMW inline-6)

120308 — B58 charging pressure (6-digit code)

A more recent BMW code convention. 120308 is a 6-hex-digit B58-specific charging-pressure code, the B58 equivalent of the older 30FF.

  • 120308 — Charging pressure control: too low (B58)

Code-catalog questions

What are BMW-specific fault codes?

4-hex-digit codes that BMW uses in addition to the SAE J2012 5-character codes. Visible only to a BMW-specific tool like Beemuu.

How do I know if a code is generic or BMW-specific?

5-character codes (P0171, P0300, U0100) are SAE. 4-hex-digit codes (29E0, 2A82, 120308) are BMW-specific.

What if my code isn’t in this catalog?

Use the live lookup. The catalog has 444 entries; the API at api.beemuu.com/api/dtc/<code> returns a 404 with a not-found error for codes that aren’t seeded yet.
