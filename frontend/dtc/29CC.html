Community repair opinions

The same code means different work depending on who is paying. These are the recorded DIY, independent-shop and dealer paths:

PerspectiveActionCostTimeDifficulty
DIYSwap the ignition coils and spark plugs from the flagged cylinders with different cylinders and re-scan — if the misfire follows the part, replace that part; fuel-soaked plugs after a rough cold start point at leaking injectors instead
5post — rough idle, misfires and codes galore thread		~$2501-2 hoursEasy
On the N54, exhaust every plug and coil swap before touching injectors — they run around $200 each and need DME calibration after fitting. If misfires survive brand-new plugs, coils and injectors, suspect the MSD80 DME injector-driver MOSFETs (30BA/30BB territory) rather than buying a second round of parts.
Independent shopReproduce the cold-start misfire, pull plugs on the flagged cylinders (fuel-soaked confirms a leaking injector), run a compression check, replace the affected injectors with the improved part, and code the injector calibration values to the DME
Burger Motorsports — N54 MSD80 ECU MOSFET failure write-up		~$9003-5 hoursModerate
The bulletin logic scales with spread: one cylinder gets one injector, multiple cylinders on the same bank get all three of that bank, and three or more cylinders get the full set of six — plus new plugs on any cylinder found fuel-soaked. A good indie will also load-test the DME driver stage before condemning a full set.
DealerPerform the SI B 13 04 09 cold-start misfire procedure: reproduce the cold-start rough running, replace the affected high-pressure injectors with the improved part (13 53 7 585 261), replace soaked spark plugs, and perform injector calibration per SI B 12 26 08
dot.report — NHTSA bulletin summary quoting SI B 13 04 09		~$22001 dayAdvanced
The bulletin applies to N54 cars produced up to 09/2008 with cold-start rough running and misfire codes (29CC with 29CF-29D2 companions). For misfires that are NOT cold-start related, bulletins B12 05 09 and B12 06 09 cover a DME software error — ask which path was followed before approving a full injector set.

Frequently asked

Is code 29CC safe to clear?

Clearing is only safe once you have read and recorded the freeze frame. Re-appearing after a clear is the useful signal; clearing without recording destroys it.

Is 29CC a BMW-specific or a generic code?

This is a BMW manufacturer hex code. A generic OBD-II tool will not show it — you need BMW-protocol access over K+DCAN or ENET/DoIP.
