Profile questions

Where do the profiles come from?

The community (community/profiles/*.toml). Each profile is a plain TOML file you can read, fork and PR.

Can I add my own engine?

Yes — copy an existing profile, change the queries and decodes, and open a PR. See community/profiles/README.md.
