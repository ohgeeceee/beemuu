          Session & security
          
        
          
          
          
          
          
          Locked
          
        
          
        
          
          Security unlock uses the module's seed/key algorithm. Only the
          simulator's algorithm is built in; real BMW modules need their
          per-ECU algorithm added in commands.rs. Some service
          functions require an unlocked extended session.
        
          
      
          
      
          
        
          FRM coding dump (E90)
          
        
          
          
          
            
          
              
          FRM coding dump (E90)
          
              
          
                Read-only identify + local-ID/DID probe of FRM (0x72).
                Mirror-fold state: Unknown
                — no bit map is shipped.
              
          
              
          Not connected
          
            
          
            READ ONLY
            
          
          
        
          
        
          
          Research dump for a later coding map. This does
          not turn automatic mirror folding on or off.
          To change the setting on the car, use NCS Expert + NCS Dummy.
          Harness: docs/validation/coding-mirror-fold.md.
          A full probe can take several minutes on a real FRM (each
          unanswered ID waits for a timeout).
        
          
      
          
      
          
        
          Service functions
          
        
          
        
          
          Entries tagged UNVERIFIED use routine IDs that
          have not been validated on a real chassis (simulator-grade).
          Running one shows an extra confirmation. Validation harness:
          docs/validation/service-functions.md.
